## 4. 论文机制对应、教学简化与扩展计划

- 对应 EChecker “历史实际依赖图 + 变化签名触发缓存失效 + 当前声明图重算”的机制；删除 include 属于“实际依赖减少”的方向，应与新增 include 一样触发保守刷新。
- 教学实现是受限子集：两个固定对象目标、顶层 C/H、显式规则、简单变量、受限 CFLAGS；不覆盖隐式规则、递归 Make 等。
- 扩展计划：将“全目标保守刷新”细化为仅刷新受影响目标，并用全量扫描对照验证不漏边。
